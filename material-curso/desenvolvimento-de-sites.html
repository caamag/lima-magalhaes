1. Como a internet funciona

Todo dia você abre sites: Instagram, Google, a página do banco. Mas o que acontece entre você digitar um endereço e a página aparecer na tela? Vamos simplificar.

🧑‍💻Vocêdigita um endereço no navegador
→
🌐Interneto pedido viaja até o computador onde o site está guardado
→
🗄️Servidorencontra os arquivos do site e devolve
→
🖥️Navegadorlê os arquivos e monta a página na tela
Pense numa loja

O domínio (www.minhaloja.com.br) é o endereço da loja. A hospedagem é o terreno onde a loja foi construída. Os arquivos do site são a loja em si: prateleiras, produtos, decoração. E o navegador é o carro que leva o cliente até lá.

O ponto mais importante para nós: um site é um conjunto de arquivos de texto. Não tem mágica. São arquivos que o navegador sabe ler e transformar em uma página bonita. Neste curso, você vai aprender a escrever esses arquivos.

Você sabia?

Navegador é o programa que você usa para acessar sites: Google Chrome, Safari, Microsoft Edge e Firefox são navegadores. Neste curso vamos usar o Google Chrome.

2. As três linguagens da web

Quase todo site do mundo é feito com três linguagens que trabalham juntas. Cada uma tem uma função:

EstruturaHTMLDiz o que existe na página: um título, um texto, uma foto, um botão.
AparênciaCSSDiz como isso aparece: cores, tamanhos, fontes, posição.
ComportamentoJavaScriptDiz o que acontece quando você interage: clicar, digitar, abrir um menu.
Pense numa casa

HTML são as paredes, portas e janelas. CSS é a pintura, os móveis e a decoração. JavaScript é a parte elétrica: o interruptor que acende a luz, a campainha que toca.

Hoje vamos focar no HTML. Na aula 2 entra o CSS, e na aula 4, o JavaScript.

3. Preparando o computador

Para criar sites, você só precisa de duas ferramentas gratuitas: um navegador (que você já tem) e um editor de código, que é como um bloco de notas feito para programar.

  1. Instale o Google ChromeSe ainda não tiver, baixe em google.com/chrome.
  2. Instale o Visual Studio Code (VS Code)Baixe em code.visualstudio.com e instale clicando em “Próximo” até o fim. É o editor de código mais usado do mundo e é gratuito.
  3. Crie uma pasta para o cursoNa sua Área de Trabalho, crie uma pasta chamada curso-sites. Dentro dela, crie outra chamada aula-01. Tudo o que fizermos hoje fica aqui.
  4. Abra a pasta no VS CodeNo VS Code, clique em File → Open Folder (Arquivo → Abrir pasta) e escolha a pasta aula-01.
  5. Crie o arquivo index.htmlNo painel da esquerda, clique no ícone de “novo arquivo” e digite index.html. O nome index é o padrão para a página principal de um site.
  6. Instale a extensão Live ServerNo VS Code, clique no ícone de quadradinhos à esquerda (Extensões), pesquise Live Server e clique em Install. Ela abre a sua página no navegador e atualiza sozinha sempre que você salvar.
Atenção à extensão do arquivo

O final do nome do arquivo (.html) diz ao computador que tipo de arquivo ele é. Se o arquivo ficar como index.html.txt, o navegador não vai entendê-lo como página. Crie sempre pelo VS Code para evitar esse problema.

Atalho que você vai usar o tempo todo

Ctrl + S salva o arquivo (no Mac, Cmd + S). Se você mudou o código e nada mudou na tela, a primeira pergunta é sempre: salvei?

4. O que é HTML

HTML significa HyperText Markup Language, ou “linguagem de marcação de hipertexto”. O nome assusta, mas a ideia é simples: você marca cada parte do conteúdo com uma etiqueta, dizendo ao navegador o que ela é.

Essas etiquetas se chamam tags. Uma tag é escrita entre os sinais < e >. Veja como funciona:

<p>abre a tag Olá, mundo!conteúdo </p>fecha a tag

A tag <p> significa “parágrafo”. Tudo o que estiver entre a abertura <p> e o fechamento </p> é um parágrafo. Repare na barra / na tag de fechamento: é ela que diz “o parágrafo termina aqui”.

Pense numa mudança

Quando você faz uma mudança, escreve nas caixas “cozinha”, “quarto”, “livros”. A caixa não muda o que está dentro, mas ajuda a saber onde cada coisa vai. As tags fazem o mesmo: elas não aparecem na tela, só dizem ao navegador o que é cada conteúdo.

Atributos: informações extras de uma tag

Algumas tags precisam de mais informações. Um link, por exemplo, precisa saber para onde leva. Essas informações extras são os atributos, escritos dentro da tag de abertura no formato nome="valor":

Aqui, href é o atributo e "https://www.google.com" é o valor dele, sempre entre aspas.

CódigoO que significa

<html lang="pt-BR">A caixa que guarda a página inteira. O lang diz que o conteúdo está em português do Brasil.

Atalho do VS Code

Em um arquivo .html vazio, digite apenas ! e aperte Enter. O VS Code escreve a estrutura básica inteira para você. Use depois que tiver entendido cada linha.

6. As tags essenciais

Com poucas tags você já consegue montar uma página completa. Todos os exemplos abaixo vão dentro do <body>.

Títulos: <h1> a <h6>

Existem seis níveis de título. O <h1> é o mais importante (o título principal da página) e o <h6> o menos importante. Use só um <h1> por página, como a manchete de um jornal.

Parágrafos e destaques: <p>, <strong> e <em>

Cada bloco de texto vai em um <p>. Dentro dele, <strong> deixa um trecho importante (em negrito) e <em> dá ênfase (em itálico).

Por que meu “Enter” não funciona?

O navegador ignora as quebras de linha e os espaços extras que você digita no código. Para criar um novo parágrafo, use um novo <p>. Isso confunde todo mundo no começo, e é normal.

Listas: <ul>, <ol> e <li>

<ul> cria uma lista com marcadores (bolinhas) e <ol> uma lista numerada. Cada item vai dentro de um <li> (de list item).

Links: <a>

O link é o que faz da internet uma “rede”: ele conecta uma página a outra. O endereço de destino vai no atributo href. Com target="_blank", o link abre em uma nova aba.

Imagens: <img>

A tag de imagem é diferente: ela não tem fechamento, porque não tem conteúdo dentro. Ela precisa de dois atributos:

  • src (de source, “origem”): onde está a imagem.
  • alt (de alternative): uma descrição da imagem. Ela aparece se a imagem não carregar e é lida em voz alta para pessoas cegas que usam leitores de tela.

Para usar uma foto sua, coloque o arquivo de imagem dentro da mesma pasta do index.html e escreva só o nome dele:

Nomes de arquivo

Use nomes sem acentos, sem espaços e em letras minúsculas, separando palavras com hífen: minha-foto.jpg e não Minha Foto.JPG. Isso evita muitos problemas, principalmente quando o site for publicado.

Comentários: anotações para você

Tudo o que estiver entre <!-- e --> é um comentário: o navegador ignora. Use para deixar lembretes no código.

7. Caixas dentro de caixas

Você já deve ter percebido que algumas tags ficam dentro de outras: o <li> fica dentro do <ul>, o <strong> fica dentro do <p>, e tudo fica dentro do <body>. Isso se chama aninhamento.

A regra de ouro: a última caixa aberta é a primeira a ser fechada.

Para enxergar melhor essas caixas, usamos a indentação: o recuo com espaços no início da linha. Cada tag que está dentro de outra ganha um recuo a mais. O navegador não se importa com isso, mas fica muito mais fácil para você ler e encontrar erros.

Deixe o VS Code arrumar para você

Clique com o botão direito no código e escolha Format Document (Formatar documento), ou use Shift + Alt + F. O VS Code arruma a indentação do arquivo inteiro.

Exercício: a sua página “Sobre mim”

Crie, na pasta aula-01, um arquivo chamado sobre-mim.html com uma página que apresente você. Ela precisa ter:

  • A estrutura básica completa, com um <title> com o seu nome
  • Um <h1> com o seu nome
  • Uma foto (sua ou de algo que você goste) com um alt descritivo
  • Um parágrafo de apresentação, com pelo menos uma palavra em <strong>
  • Um <h2> “O que eu gosto de fazer” seguido de uma lista com marcadores
  • Um <h2> “Por que estou fazendo este curso” com um parágrafo
  • Um link para uma rede social ou site de que você goste, abrindo em nova aba
Terminou antes?

Adicione uma lista numerada com “3 lugares que quero conhecer” e um link no fim da página que leve de volta para o index.html, usando href="index.html".

Glossário da aula

NavegadorPrograma que abre sites, como o Chrome.
ServidorComputador ligado o tempo todo que guarda os arquivos de um site.
DomínioO endereço de um site, como meusite.com.br.
HospedagemO serviço que guarda o site em um servidor.
Editor de códigoPrograma para escrever código. Usamos o VS Code.
HTMLLinguagem que define a estrutura e o conteúdo da página.
TagEtiqueta entre < > que marca o que é cada conteúdo.
AtributoInformação extra dentro da tag, como href ou src.
AninhamentoTags dentro de outras tags, como caixas dentro de caixas.
IndentaçãoRecuo no início da linha que mostra o que está dentro do quê.

Revisão rápida

  1. Um site é um conjunto de arquivos que o navegador lê e transforma em página.
  2. HTML é a estrutura, CSS é a aparência e JavaScript é o comportamento.
  3. Tags marcam o conteúdo: abrem com <tag> e fecham com </tag>.
  4. O que o visitante vê fica no <body>; informações para o navegador ficam no <head>.
  5. Salvou? Atualizou? Fechou todas as tags? Essas três perguntas resolvem a maioria dos problemas.
